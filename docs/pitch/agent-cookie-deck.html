The problem

Every agent you meet is a stranger. The web had this problem in 1994.

  • The same interview, every time. Language, tone, size, taste, address: a new assistant asks it all, and so does every store it talks to.
  • One company holds it all. Each assistant keeps its own memory. Switching means starting over or handing over everything.
  • No receipts. Nobody can tell you which agent read your address, for what, or stop the next read.

Agent Cookie
The solution

A jar you own. A cookie per agent. A receipt for every read.

Known on the first message

A new assistant gets what your policy allows, and asks nothing it already knows.

Only what the task needs

Your address goes to the one store you chose, at checkout. Your card goes to no one.

Yours to see and revoke

Every read leaves a receipt. Revoke any agent and its next read is refused.
