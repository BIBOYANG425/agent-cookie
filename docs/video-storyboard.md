# Agent Cookie · 3–5 分钟视频分镜

目标 **4 分 10 秒**，沿用 [plan 第 3 节](plan.md#3--demo-是什么样子的) 的 iMessage 主线：一句话找鞋 → 选一家 → 付款交接 → 查授权与撤销 → 回头客 → ACME / coding agent → 架构。这是录制脚本，不是已发生的结果；镜头是否可用以[证据索引](evidence/README.md)为准。A10/A17 由 B 供片，A15/A16 由 C 供片。

左侧手机 iMessage，右上控制台，右下工作台日志；需读日志时单独放大。全片保留模式角标：**Live** 仅用于当次真实请求；**Fixture replay · captured <UTC 时间>** 用于实录重放；**Sample** 标身份、地址与 ACME 商品。插入已有执行片段时全程显示 **Recorded run · <录制日期>**，并保留当时的数据模式。

## 失败、阻塞与短版

先从 reset 连跑两遍，记录每步真实耗时再剪辑。请求超过 20 秒或出错时，只能切到已有且核验过的 **Recorded run** 并展示当时日志；没有成功原片就保留失败或删段，不合成预期消息。

若 A15/A16 未完成，删除 2:30–3:30 的成功演示，保留一句“第三方 memory 接入仍待 note 生命周期契约补齐”，全片约 **3 分 10 秒**。C11 的 P1 BLOCKED 不阻塞短版稿。若 Claude Desktop 回头客段也无可核验原片，以 25 秒控制台授权解释替换，保持至少 3 分钟。没有 A17 实际 iMessage 原片时，不能标记正式视频已完成。

五分钟上限内可将 A16 两次运行各扩展到 40 秒；不能用时长隐藏失败或把部分接入说完整。
