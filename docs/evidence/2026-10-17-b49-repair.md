## 当前删除与恢复

`forgetLearning({field})` 一次请求在 SQLite 事务内暂停学习、增加持久 epoch、删除该字段当前贡献/卡片、保存只含 opaque IDs 的恢复任务和 keyed suppression digest。Git 当前贡献、预览意图提取和卡片随后一个 commit 清理。失败返回 202/pending，保持暂停并禁止恢复；启动时重试。贡献写入与暂停/forget 串行，旧学习响应不能复活。

回归覆盖事务回滚、投影故障、进程重开恢复、迟到响应、后续重复偏好、未知/商家请求拒绝和多值歧义。iMessage 用户只说一个值时，不会悄悄删除同类别其他值。成功只声称当前偏好及证据被移除，`historyErased:false`；历史 Git commits/备份仍保留，SQLite 和 Git 不是一个跨存储 ACID 事务。
