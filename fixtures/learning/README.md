# Sample 学习桩

`console.json` 是 C19 控制台用的显式 Sample 数据，不是 B 的模型提取结果，也不是已冻结的 HTTP 响应。字段名、证据来源与数据形状标记为 `TODO(contract)`，待 B 的学习计划及 A 类型到达后对齐。

- `empty`：无学习条目。
- `candidate`：一句“周末又去徒步，上次脚湿透了”生成两个不同字段的候选；两个字段不构成同一字段的两个来源。
- `learned`：另外加入一段较早的独立 Sample 对话，两个字段各有两个独立来源，晋升 medium。当前“帮我找双鞋”不被当作证明防水偏好的第二条证据。
- 每条 `id` 对应一条贡献；`sources` 指明该贡献的来源。撤销必须按贡献 ID 操作。
- 证据均为合成片段且 ≤200 Unicode 字符；这里的 pref.* 不改变工作台商家字段放行策略。

完整真实链路与排序证据状态见 `docs/evidence/learning.md`。
