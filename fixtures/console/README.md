# Sample console presentation

`generalized.json` 仅用于未连接工作台的本地控制台；不改变 fixtures/memory 种子或真实授权策略。常用尺码 L、预算100与本次夹克请求 size=M、budget=85 分开；pref.*、回执及一个可选 needs 事件用于通用界面核验。

needs 数字和不可用字段是预设 Sample，不能作为真实后台或模型证据。授权A/B各四个字段；地址回执仅给示例中选择的B。未接真实请求、真实报价或支付。学习模型 ID 同样是展示用预设元数据。当前截图见 docs/evidence/console/README.md。
